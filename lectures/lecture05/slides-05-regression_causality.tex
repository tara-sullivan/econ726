\begin{frame}{Regression and causality}

Regression gives the best linear approximation to the CEF, in a MSE sense
\begin{itemize}
    \item But when does a regression represent something causal?
\end{itemize}

\vspace{2ex}
A regression is \textbf{causal} when the CEF it approximates is causal
\begin{itemize}
    \item Helpful to think of a CEF being causal by using the potential outcomes framework
    \item CEF is causal when it describes differences in average potential outcomes for a fixed reference population
\end{itemize}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Review - Potential Outcomes framework}

Consider the relationship between future earnings $Y_i$ and whether $i$ attends college, denoted by $D_i$
 
\begin{table}
\begin{tabular}{ll}
$D_i \in \{0, 1\}$ &Binary \textbf{treatment variable} for individual $i$ \\ 
$Y_i$ &\textbf{Outcome} \\
&Measure of earnings for individual $i$\\
% \pause
\hline
$Y_{i} (1)$ &\textbf{Treatment potential outcome} \\
&Earnings if individual $i$ goes to college ($D_i=1$) \\
&Alternative notation: $Y_i(1)$, $Y_i^1$, $y_{i1}$ \\
\hline
$Y_{i} (0)$ &\textbf{Control potential outcome} \\
&Earnings if individual $i$ does not go to college ($D_i=0$)  \\
&Alternative notation: $Y_i(0)$, $Y_i^0$, $y_{i0}$ \\\\
\end{tabular}
\end{table}

\begin{itemize}
    \item $Y_{i} (0)$ is earnings of an individual had they not gone to college, \emph{irrespective of whether they actually went}
    \item Causal effect college attendance for individual $i$ is the difference $Y_{i} (1) - Y_{i} (0)$
\end{itemize}

% \pause
\vspace{2ex}
Observed outcome $Y_i$ can be written as:
\begin{align*}
    Y_i =& \begin{cases}
    Y_{i} (1) &\text{if} D_i = 1 \\
    Y_{i} (0) &\text{if} D_i = 0
    \end{cases} \\
    =& Y_{i} (0) + (Y_{i} (1) - Y_{i} (0)) D_i
\end{align*}
We can see $Y_{i} (0)$ or $Y_{i} (1)$ in the data, but never both
\end{frame}

\begin{frame}{Review - Fundamental problem of causal inference}

\begin{columns}

\column{0.75\linewidth}

\textbf{Problem:}
\begin{itemize}
    \item If an individual is treated ($D_i = 1$), we never observe the outcome in which they are not treated ($Y_{i} (0)$)
    \item If an individual is not treated ($D_i = 0$), we never observe the outcome in which they are treated ($Y_{i} (1)$)
\end{itemize}

\vspace{2ex}
\textbf{\color{HunterPurple} The causal effect $\mathbf{Y (1) - Y (0)}$ is unidentifiable}

\begin{table}
\begin{tabular}{lll}
Group &$Y (1)$ &$Y (0)$ \\
$D = 1$ &Observable as $Y$ &Unobservable counterfactual \\
$D = 0$ &Unobservable counterfactual &Observable as $Y$
\end{tabular}
\end{table}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Stable Unit Treatment Value Assumption (SUTVA)}

To link potential outcomes to observed data, we need two assumptions; together, these are known as \textbf{SUTVA}

\vspace{2ex}
\textbf{1. Consistency:} we observe $Y_i = Y_i(D_i)$
\begin{itemize}
    \item Equivalently, $Y_i = D_i Y_i(1) + (1 - D_i) Y_i(0)$
    \item Rules out hidden versions of treatment: $D_i = 1$ must mean the same thing for everyone
    \item e.g., if ``college'' includes both a 2-year and 4-year degree, $Y_i(1)$ is not well-defined
\end{itemize}

\pause
\vspace{2ex}
\textbf{2. No interference:} $i$'s potential outcomes depend only on $i$'s own treatment, not on anyone else's
\begin{itemize}
    \item Built into the notation $Y_i(d)$, which is indexed only by $i$'s own treatment status
    \item Rules out spillovers, externalities, and general equilibrium effects
\end{itemize}

\pause
\vspace{2ex}
\textbf{When might no interference fail?}
\begin{itemize}
    \item Vaccines: if many people are vaccinated, herd immunity protects the unvaccinated too
    \item College: if many people get a degree, the college wage premium may fall
\end{itemize}

\vspace{2ex}
{\footnotesize Source: Chernozhukov et al. (2025), Assumptions 2.1.1--2.1.2 and Section 2.4}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Types of comparisons}

    Causal effect of interest in often \textbf{Average Treatment Effect}:
    \begin{equation*}
        \EE [Y(1) - Y(0)] = \EE [Y(1)] - \EE [Y(0)]
    \end{equation*}
    or \textbf{Averate Treatment Effect on the Treated}:
    \begin{equation*}
        \EE [Y(1) - Y(0) \vert D = 1] = \EE [Y(1) \vert D = 1] - \EE [Y(0) \vert D = 0]
    \end{equation*}

    \vspace{2ex}
    We often discuss what is directly observable in data as the \textbf{na{i}ve comparison}. In the population this is:
    \begin{equation*}
        \EE [Y \vert D = 1] - \EE [Y \vert D = 0]
    \end{equation*}
    This is also the \textbf{average predictive effect} of treatment status on outcome.

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Na{\"i}ve comparison: $\EE [Y \vert D = 1] - \EE [Y \vert D=0]$}


Let's consider the averages of $Y_i(1)$, $Y_i(0)$, and $Y_i$:
\begin{align*}
\EE [ Y \vert D = 1 ] =& \EE [Y (0) + (Y(1) - Y (0)) D \vert D = 1]
&&\because Y = Y(0) + (Y(1) - Y(0)) D \\
=& \alert<2>{\EE[Y(1) \vert D = 1]}\\
\EE[Y \vert D = 0] 
% =& E [Y(0) + (Y(1) - Y(0)) D \vert D = 0] \\
=& \alert<2>{\EE[Y(0) \vert D = 0]}
\end{align*}

\vspace{2ex}

We can re-write the average predictive effect (observed difference) as:
\begin{align*}
\EE [Y \vert D = 1] -& \EE [Y \vert D=0] 
\onslide<2->{= \alert<2>{\EE [Y(1) \vert D=1]} - \alert<2>{\EE [Y(0) \vert D=0]} \\}
\onslide<3->{=& \EE [Y(1) \vert D=1] \alert<3>{- \EE [Y(0) \vert D = 1] + \EE [Y(0) \vert D = 1]}  - \EE [Y(0) \vert D=0] \\}
\onslide<4->{=& \underbrace<5->{\EE [Y(1) - Y(0) \vert D = 1]}_{\text{Avg. treatment effect on treated}} 
\onslide<4->{+} \underbrace<5->{\EE [Y(0) \vert D = 1] - \EE [Y(0) \vert D=0]}_{\text{Selection bias}}}
\end{align*}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Na{\"i}ve comparison (cont.)}

Observed difference in earnings equals the average treatment effect (ATE) on the treated plus selection bias:
\begin{align*}
\EE [Y \vert D = 1] - \EE [Y \vert D=0] 
% =& \EE [Y(1) \vert D=1] { - \EE [Y(0) \vert D = 1] + \EE [Y(0) \vert D = 1]}  - \EE [Y(0) \vert D=0] \\
=& \underbrace{\EE [Y(1) - Y(0) \vert D = 1]}_{\text{ATE on treated}} 
+ \underbrace{\EE [Y(0) \vert D = 1] - \EE [Y(0) \vert D=0]}_{\text{Selection bias}}
\end{align*}
ATE on treated is the average causal effect of college attendance on those who went to college:
\begin{equation*}
    \EE [Y(1) \vert D=1] - \EE [Y(0) \vert D = 1] = \EE [Y(1) - Y(0) \vert D = 1]
\end{equation*}
Selection bias:
\begin{equation*}
    \EE [Y(0) \vert D = 1] - \EE [Y(0) \vert D=0]
\end{equation*}
\textbf{What do you think selection bias looks like in this example?}

\pause
\begin{itemize}
    \item The difference in $Y_i(0)$ between those who went to college and those who didn't 
    \item Consider someone who went to college. Now assume that person didn't go. Their expected earnings may be higher than those of someone who didn't go to college at all 
    \begin{itemize}
        \item[$\implies$] Those who didn't go to college, on average, have lower values of $Y_i(0)$

        \item[$\implies$] Selection bias is positive
    \end{itemize}
\end{itemize}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Example: Marijuana and longevity}

Does smoking marijuana ($D_i$) affect longevity ($Y_i$)?
\begin{itemize}
    \item Suppose marijuana has \textbf{no causal effect} on longevity: $Y_i(1) = Y_i(0)$ for everyone
    \item[$\implies$] ATE on treated $= \EE [Y(1) - Y(0) \vert D = 1] = 0$
\end{itemize}

\vspace{2ex}
But smoking is not randomly assigned: people choose whether to smoke
\begin{itemize}
    \item Suppose smokers are more likely to make other poor health choices (e.g., drinking alcohol) that shorten life expectancy
\end{itemize}

\pause
\vspace{2ex}
Then smokers would have shorter lives \emph{even if they had not smoked}:
\begin{equation*}
    \underbrace{\EE [Y \vert D = 1] - \EE [Y \vert D=0]}_{\text{Na{\"i}ve comparison} \ < \ 0}
    = \underbrace{0}_{\text{ATE on treated}}
    + \underbrace{\EE [Y(0) \vert D = 1] - \EE [Y(0) \vert D=0]}_{\text{Selection bias} \ < \ 0}
\end{equation*}

\begin{itemize}
    \item Data show a negative relationship between smoking and longevity, even though the causal effect is zero
    \item Selection bias is negative here; in the college example it was positive
\end{itemize}

\vspace{2ex}
{\footnotesize Source: Chernozhukov et al. (2025), Example 2.1.2}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Random assignment and selection bias}

\textbf{Random assignment assumption:} treatment status is statistically independent of each potential outcome, and assignment is nontrivial:
\begin{equation*}
    D \perp Y(d) \ \text{for} \ d \in \{0, 1\}, \quad \text{and} \quad 0 < P(D = 1) < 1
\end{equation*}
\begin{itemize}
    \item Treatment assignment mechanism is purely random; knowing $D$ tells us nothing about $Y(0)$ or $Y(1)$
    \item \textbf{Positivity} ($0 < P(D=1) < 1$) ensures there are units in both treatment and control
\end{itemize}

\vspace{2ex}
Random assignment ($Y(0), Y(1) \perp D$) will solve the selection problem
\begin{itemize}
    \item Causes selection bias to equal zero
\end{itemize}
\begin{align*}
    \EE [Y(1) \vert D = 1] =& \EE[Y(1) \vert D = 0] = \EE [Y(1)] \quad \\
    \text{and} \quad \EE [Y(0) \vert D = 0] =& \EE [Y(0) \vert D = 1] = \EE [Y(0)] \\
    \implies&
    \EE [Y(0) \vert D = 1] - \EE [Y(0) \vert D = 0] = 0 \\
    \implies&
    \text{Selection bias is 0} \\
    \implies&
    \text{Na{\"i}ve comparison = ATE on treated}
\end{align*}


\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{The ideal experiment}

A useful first question for any causal claim: \textbf{what experiment would you run if you could?}
\begin{itemize}
    \item Who is randomized, into what treatment, and what outcome do you measure?
    \item If you can't describe the ideal experiment, the causal question may not be well-defined
\end{itemize}

\pause
\vspace{2ex}
\textbf{Marijuana and longevity:}
\begin{itemize}
    \item Randomly assign a group of people to smoke or not smoke marijuana for decades; compare age at death
    \item Randomization ensures smokers and non-smokers have the same $\EE [Y(0)]$ $\implies$ no selection bias
\end{itemize}

\pause
\vspace{2ex}
\textbf{College and earnings:}
\begin{itemize}
    \item Randomly admit (and require attendance from) some high school graduates; compare later earnings
\end{itemize}

\pause
\vspace{2ex}
Often the ideal experiment is unethical, infeasible, or too expensive
\begin{itemize}
    \item Rest of the course: approximating the ideal experiment with observational data
\end{itemize}

\vspace{2ex}
{\footnotesize Source: Angrist and Pischke (2009), Chapter 1}
\end{frame}

\begin{frame}{Randomization and regression}

Assume treatment effects are constant and the same for everyone
\begin{align*}
    Y_i =& Y_{i} (0) + (Y_{i} (1) - Y_{i} (0)) D_i \\
    \onslide<2->{=& 
    {\color{HunterPurple} \EE [Y_i(0)]}
    + (Y_{i} (1) - Y_i(0)) D_i 
    + Y_i(0) {\color{HunterPurple} - \EE [Y_i(0)]} \\}
    \onslide<3->{
    =& 
    \underbrace{\EE [Y_i(0)]}_{\alpha}
    + \underbrace{(Y_i(1) - Y_i(0))}_{\beta} D_i 
    + \underbrace{Y_i(0) - \EE [Y_i(0)]}_{\eta_i \text{ (Random part of $Y_i(0)$)}} \\}
    \onslide<4->{
    =& \alpha + \beta D_i + \eta_i}
\end{align*}

\onslide<5->
Evaluate this with the treatment on ($D = 1$) and off ($D = 0$):
\begin{align*}
    D = 1 \implies \EE [Y \vert D = 1] 
    &= \alpha + \beta + \EE [\eta \vert D = 1] \\
    D = 0 \implies \EE [Y \vert D = 0] 
    &= \alpha + \EE [\eta \vert D = 0] \\
\end{align*}


\onslide<6->
Then: 
\begin{align*}
    \EE [Y \vert D = 1] - \EE [Y \vert D = 0] 
    =& (\alpha + \beta + \EE [\eta \vert D = 1]) - (\alpha + \EE [\eta \vert D = 0]) \\
    =& \beta + \underbrace{(\EE [\eta \vert D = 1] - \EE [\eta \vert D = 0])}_{\text{selection bias}}
\end{align*}

\onslide<7->
Selection bias will equal zero if the correlation between the error term and treatment assignment is zero. 
\begin{itemize}
    \item If $D$ is randomly assigned, regression of $Y$ onto $D$ (and a constant) yields the causal effect $\beta$
\end{itemize}


\end{frame}

\begin{frame}{Covariates and pre-treatment heterogeneity}
    Suppose in addition to outcome ($Y$) and treatment ($D$). there are \textbf{pre-treatment} or \textbf{pre-determined} covariates $W$
    \begin{itemize}
        \item e.g. interested in treatment effect across age
    \end{itemize}

    \vspace{2ex}
    Treatment effect and naive comparison likely will not match will not match if there is pre-treatment heterogeneity
    
    \vspace{2ex}
    \textbf{Assume:} treatment assignment independent of covariates: 
    \begin{equation*}
        D \perp (Y(0), Y(1), W), \quad\text{and} \ 0 \leq P (D = 1) \leq 1
    \end{equation*}
    then:
    \begin{equation*}
        \EE [Y \vert D = d, W] = \EE [Y(d) \vert D = d, W] = \EE [Y (d) \vert W]
    \end{equation*}
    $\implies$ \textbf{conditional average treatment effects} can be estimated from conditional average predictive effects:
    \begin{equation*}
        \EE [Y(1) \vert W] - \EE [Y(0) \vert W] = \EE[Y \vert D=1, W] - \EE [Y \vert D=0, W]
    \end{equation*}
\end{frame}

\begin{frame}{Testing covariate balance}
    Random assignment assumption induces covariate balance. 
    \begin{itemize}
        \item Distribution of covariates should be the same under treatment and control:
    \end{itemize}
    \begin{equation*}
        W \vert D = 1 \sim W \vert D = 0
    \end{equation*}
    equivalently:
    \begin{equation*}
        D \vert W \sim D
    \end{equation*}
    Useful implication is:
    \begin{equation*}
        \EE [D \vert W ] = \EE [D]
    \end{equation*}
    This is testable using regression tools; the $R^2$ of a regression of $D$ on $W$ is 0 under randomization.
\end{frame}

\begin{frame}{Conditional Independence Assumption}

Last section: how do we infer causal effects when we have \textbf{random assignment} of treatment.

\begin{itemize}
    \item [$\implies$] Independence of potential outcomes and the treatment
     \item [$\implies$] $Y(0), Y(1) \perp D$
     \item [$\implies$] randomization
\end{itemize} 

\vspace{2ex}
What happens when we don't have independence? Meaning the occurrence of $D$ influences the occurrence of $Y(0)$ and $Y(1)$ (or vice versa)?

\vspace{3ex}
Perhaps we can condition on certain variables $X$, such that the treatment $D_i$ and the potential outcomes $Y_i(1), Y_i(0)$ LOOK independent
\begin{equation*}
    \{Y_i(0), Y_i(1)\} \perp D_i \vert X_i
\end{equation*}
\begin{itemize}
    \item Think of treatment $D_i$ as generated randomly (independent of potential outcomes) \textbf{conditional} on some pre-treatment variable $X$
    \item [$\implies$] can learn about average causal treatment effects by regression of $Y_i$ on $D_i$ and $X_i$. 
\end{itemize}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Conditional independence}

Conditional independence assumption: 
\begin{equation*}
    \{Y_i(0), Y_i(1)\} \perp D_i \vert X_i
\end{equation*}
Intuitively: occurrence of $D_i$ does not influence the occurrence of $Y_i(0)$ or $Y_i(1)$, or vice versa, conditional on knowing $X_i$:
\begin{align*}
    \EE[Y_i(0) \vert D_i, X_i] &= \EE [Y_i(0) \vert X_i] \\
    \EE[Y_i(1) \vert D_i, X_i] &= \EE [Y_i(1) \vert X_i] 
\end{align*}

\begin{frame}{Selection bias under CIA}

Under conditional independence assumption, selection bias disappears conditional on $X_i$:
\begin{align*}
    \EE [Y_i(0) \vert X_i, D_i = 1] - \EE [Y_i(0) \vert X_i, D_i = 0]
    =& \EE [Y_i(0) \vert X_i, D_i = 0] - \EE [Y_i(0) \vert X_i, D_i = 0] \\
    =& 0
\end{align*}
So we can write the difference in observed outcomes \textbf{conditional on $X_i$} as:
\begin{align*}
    \EE [Y_i \vert X_i, D_i = 1] - \EE [Y_i \vert X_i, D_i = 0] 
    &= \EE [Y_i(1) \vert X_i, D_i = 1] - \EE [Y_i(0) \vert X_i, D_i = 0] \\
    &= \EE [Y_i(1) \vert X_i] - \EE [Y_i(0) \vert X_i] \\
    &= \EE [Y_i(1) - Y_i(0) \vert X_i]
\end{align*}
Given the CIA, comparisons of average earnings (conditional on $X_i$) have a causal interpretation
\end{frame}

\draw (X) edge[->] (Y);
\end{tikzpicture}
\end{figure}
\end{columns}

\pause
\vspace{2ex}
\textbf{Without adjusting for $X$:} higher $D$ predicts higher $X$, which predicts lower $Y$
\begin{equation*}
    \EE [Y \vert D = 1] - \EE [Y \vert D = 0] < 0
\end{equation*}
\begin{itemize}
    \item Predictive effect $\neq$ causal effect $\implies$ \textbf{confounding} (selection bias)
\end{itemize}

\pause
\vspace{2ex}
\textbf{Conditioning on $X$} removes the selection bias:
\begin{equation*}
    \EE [Y \vert D = 1, X] - \EE [Y \vert D = 0, X]  = \EE [Y(1) - Y(0) \vert X]
\end{equation*}
provided that, conditional on $X$, variation in $D$ is independent of potential outcomes:
\begin{itemize}
    \item \textbf{Conditional ignorability:} $D \perp Y(d) \vert X$ for each $d$ \quad (i.e., the CIA)
    \item \textbf{Consistency:} $Y = Y(D)$
\end{itemize}

\vspace{2ex}
{\footnotesize Source: Chernozhukov et al. (2025), Section 5.2 and Assumption 5.2.1}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Identification by conditioning}

Ignorability says variation in $D$ is \textbf{as good as random} conditional on $X$
\begin{itemize}
    \item Among units with the same covariates ($X = x$), treatment variation $D \vert X = x$ is produced \emph{as if} by an RCT
    \item ``Ignorable'': distribution of $Y(d)$ depends only on $X$, not on $D$
    \item Also called \textbf{conditional exogeneity} or the \textbf{conditional independence assumption} (CIA) in econometrics
\end{itemize}

\pause
\vspace{2ex}
\textbf{Conditioning (adjustment) strategy:} compare treated and control units with identical characteristics $X = x$
\begin{itemize}
    \item Produces a different contrast for every value of $X$
    \item Average these contrasts over the distribution of $X$ to get a summary measure of the causal effect
\end{itemize}

\pause
\vspace{2ex}
For this to work, we need \textbf{both} treated and control units at every value of $X$
\begin{itemize}
    \item The \textbf{propensity score} $p(X) := P(D = 1 \vert X)$ plays a key role
\end{itemize}

\vspace{2ex}
{\footnotesize Source: Chernozhukov et al. (2025), Section 5.2}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Overlap assumption}

\textbf{Overlap (full support):} the propensity score is non-degenerate
\begin{equation*}
    p(X) := P(D = 1 \vert X), \qquad P\big(0 < p(X) < 1\big) = 1
\end{equation*}
\begin{itemize}
    \item Requires variation in $D$ at each value $x$ in the support of $X$
    \item Equivalently: $\text{support}(D, X) = \{0, 1\} \times \text{support}(X)$
    \item Conditional analogue of \textbf{positivity} under random assignment ($0 < P(D=1) < 1$)
\end{itemize}

\pause
\vspace{2ex}
\textbf{Without overlap:} at some values $x$ there are only treated (or only control) units
\begin{itemize}
    \item Cannot construct a contrast between treated and control at those $x$
    \item[$\implies$] Cannot learn the conditional average treatment effect at those values of $X$
    \item[$\implies$] Cannot learn the unconditional average treatment effect either
\end{itemize}

\pause
\vspace{2ex}
\textbf{Example:} if every heavy drinker smokes marijuana, then $p(\text{heavy drinker}) = 1$
\begin{itemize}
    \item No non-smoking heavy drinkers to compare against
\end{itemize}

\vspace{2ex}
{\footnotesize Source: Chernozhukov et al. (2025), Assumption 5.2.2 and Remark 5.2.1}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Conditioning on $X$ removes selection bias}

\textbf{Assumptions:}
\begin{enumerate}
    \item \textbf{Consistency:} $Y = Y(D)$
    \item \textbf{Conditional ignorability:} $D \perp Y(d) \vert X$ for each $d$
    \item \textbf{Overlap:} $P\big(0 < p(X) < 1\big) = 1$
\end{enumerate}

\pause
\vspace{2ex}
\textbf{Theorem (conditioning on $X$ removes selection bias):} Under conditional ignorability and overlap,
\begin{equation*}
    \EE [Y \vert D = d, X] = \EE [Y(d) \vert D = d, X] = \EE [Y(d) \vert X]
\end{equation*}
\begin{itemize}
    \item The CEF of observed $Y$ given $D = d$ and $X$ recovers the CEF of the potential outcome $Y(d)$ given $X$
\end{itemize}

\pause
\vspace{2ex}
\textbf{Why?}
\begin{itemize}
    \item Overlap makes it possible to condition on $\{D = 0, X\}$ and $\{D = 1, X\}$ at every value in the support of $X$
    \item First equality: consistency
    \item Second equality: ignorability
\end{itemize}

\vspace{2ex}
{\footnotesize Source: Chernozhukov et al. (2025), Theorem 5.2.1}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Predictive effects and treatment effects}

\textbf{Predictive effects} (computable from observed data):
\begin{align*}
    \text{Conditional avg. predictive effect (CAPE):} \quad & \pi(X) = \EE [Y \vert D=1, X] - \EE [Y \vert D=0, X] \\
    \text{Avg. predictive effect (APE):} \quad & \pi = \EE [\pi(X)]
\end{align*}
\textbf{Treatment effects} (defined by potential outcomes):
\begin{align*}
    \text{Conditional avg. treatment effect (CATE):} \quad & \delta(X) = \EE [Y(1) \vert X] - \EE [Y(0) \vert X] \\
    \text{Avg. treatment effect (ATE):} \quad & \delta = \EE [\delta(X)]
\end{align*}

\pause
\vspace{2ex}
By the theorem, the conditional average predictive effect equals the conditional average treatment effect:
\begin{equation*}
    \pi(X) = \delta(X)
\end{equation*}
Averaging over $X$, the APE and ATE also agree:
\begin{equation*}
    \delta = \EE [\delta(X)] = \EE [\pi(X)] = \pi
\end{equation*}

\pause
\vspace{2ex}
\begin{itemize}
    \item $\pi(X)$ is computable from data $\implies$ we can learn $\delta(X)$ and $\delta$
    \item Note: $\pi = \EE[\pi(X)]$ generally differs from the na{\"i}ve comparison $\EE [Y \vert D=1] - \EE [Y \vert D=0]$
\end{itemize}

\vspace{2ex}
{\footnotesize Source: Chernozhukov et al. (2025), Section 5.2}
\end{frame}

\begin{frame}{When treatment takes on more than two values}

Expanding CIA assumption to relations that can take on more than two values, such as when $s_i = \{0, 1, \dots, 16\}$ equals years of schooling:
\begin{equation*}
    Y_{i} (s) = f_i (s)
\end{equation*}
Individual specific function:
\begin{itemize}
    \item Potential earnings that person $i$ would receive after obtaining $s$ years of education
    \item What would $i$ learn for any value of schooling
\end{itemize}

\vspace{2ex}
If $s$ could only take on two values, $s=12$ and $s=16$, then we're considering the value of college vs. no college:
\begin{equation*}
    Y_i(0) = f_i(12), \quad \quad Y_i(1) = f_i(16)
\end{equation*}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{CIA with non-binary treatment}

CIA in this more general set-up:
\begin{equation*}
    Y_{i} (s) \perp s_i \vert X_i, \quad \forall s_i
\end{equation*}
\begin{itemize}
    \item In randomized experiments (RCTs), $s_i$ is randomly assigned based on covariates $X_i$
    \item In observational studies, the CIA means $s_i$ is \textbf{as good as randomly assigned} conditional on $X_i$
\end{itemize}
Under conditional independence assumption, comparisons of average earnings across schooling levels have a causal interpretation:
\begin{equation*}
    \EE [Y_i \vert X_i, s_i = s] - \EE[Y_i \vert X_i, s_i = s - 1] = \EE [f_i(s) - f_i(s - 1) \vert X_i]
\end{equation*}
For example, average causal effect of high school graduation:
\begin{align*}
    \EE [Y_i \vert X_i, s_i = 12] - \EE[Y_i \vert X_i, s_i = 11] =& \EE [f_i (12) \vert X_i, s_i = 12] - \EE [f_i (11) \vert X_i, s_i = 11] \\
    =& \EE [f_i(12) - f_i(11) \vert X_i, s_i = 12] 
\end{align*}
\begin{itemize}
    \item Here, selection bias would come from the differences in potential earnings of high school graduates and non-graduates
    \item Under CIA, high school graduation is independent of potential earnings conditional on $X_i$, so selection bias disappears
\end{itemize}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{CIA and regression}

Regression is an empirical strategy that turns CIA into causal effects:
\begin{itemize}
    \item Assume $f_i(s)$ is linear in $s$, and the same for everyone, except for an additive term $\eta_i$:
    \begin{equation*}
        f_i(s) = \alpha + \rho s + \eta_i
    \end{equation*}
    \item \textbf{Linear constant effects model}: equation is linear, and the functional relationship is the same for everyone
    \item Only individual-specific part of $f_i(s)$ is mean-zero $\eta_i$, which captures unobserved factors that determine potential earnings
\end{itemize}
Observed value will be:
\begin{equation*}
    Y_i = \alpha + \rho s_i + \eta_i, 
\end{equation*}
Note that $s_i$ is correlated with $\eta_i$: $\EE [\eta_i \vert s_i] \neq 0$. If we ran this regression, we'd expect selection bias to impact our results.

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{CIA and regression (cont.)}

Assume CIA holds, and $\eta_i$ has the form:
\begin{equation*}
    \eta_i = X_i^\prime \gamma + v_i
\end{equation*}
where: 
\begin{itemize}
    \item $\gamma$ is a vector of population regression coefficients that satisfies $\EE [\eta_i \vert X_i] = X_i^\prime \gamma$
    \item $v_i$ and $X_i$ are uncorrelated by construction
\end{itemize}
Then, because of the CIA:
\begin{align*}
    \EE [f_i(s) \vert X_i, s_i] &= \EE[f_i (s) \vert X_i] \\
    &= \alpha + \rho s + \EE [\eta_i \vert X] \\
    &= \alpha + \rho s + X_i^\prime \gamma
\end{align*}
The residual in the linear causal model $v_i$ is uncorrelated with $s_i$ and $X_i$, and $\rho$ is the causal effect of interest:
\begin{equation*}
    Y_i = \alpha + \rho s_i + X_i^\prime + v_i
\end{equation*}

\end{frame}


%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Regression takeaways}

We just discussed how CIA + linear causal model yields a causal interpretation of CEF
\begin{itemize}
    \item Linear causal model: $Y_i = \alpha + \rho s_i + \eta_i$
    \item If CIA holds given some variables $X_i$: $Y_{0i}, Y_{1i} \perp s_i \vert X_i$
    \item Our regression function has a causal interpretation: $Y_i = \alpha + \rho s_i + X_i^\prime \gamma + v_i$
    \begin{itemize}
        \item $\rho$ is the causal effect of $s_i$ on $Y_i$
    \end{itemize}
    \item CEF given by:
    \begin{equation*}
        \EE [Y_i \vert X_i, s_i] = \alpha + \rho s_i + X_i^\prime \gamma
    \end{equation*}
\end{itemize}
