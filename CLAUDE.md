This is the repository for a Master's level economics course on Public Policy Analysis. The goal of this class is to learn methods for conducting causal inference on observational data. Your job is to:
* When instructed, proofread various elements of the course (syllabus, lectures, etc)
* Provide suggestions on improving course materials

You should NEVER re-write course elements without explicit permission. All edits must be confirmed before proceeding.

Eventually, I hope to incorporate more coding elements into the course materials. When we get to that stage, remember: parsimony is key. Code should be short, concise, and precise. Python is the primary language of this course
