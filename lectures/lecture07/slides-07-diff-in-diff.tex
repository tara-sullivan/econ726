\begin{frame}{Intro}

Key to causal inference in Chapter 3 of MHE is to control for confounding factors
\begin{itemize}
    \item What if the confounding variables are unobservable?
\end{itemize}

Today: control for unobserved variables that are fixed by time or by cohort
\begin{itemize}
    \item Fixed effects
    \item Differences-in-differences
\end{itemize}

\end{frame}


%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Motivating example}

Define
\begin{itemize}
    \item $Y_i$: the (log) wages of individual $i$
    \item $D_i$: Union membership
\end{itemize}
Does collective bargaining increase wages? Or would those workers have earned more anyway, perhaps because they are more experienced or skilled?

\vspace{3ex}
Potential outcomes:
\begin{itemize}
    \item $Y_i (1)$: Treatment potential outcome
    \begin{itemize}
        \item The value of $Y_i$ under treatment, irrespective of whether $i$ was treated
        \item Wages for $i$ if unionized, irrespective of whether they were in a union
    \end{itemize}
    \item $Y_i (0)$: Control potential outcome
    \begin{itemize}
        \item Wages for $i$ if not unionized, irrespective of whether $i$ was in a union
    \end{itemize}
\end{itemize}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Time dimension}

Adding a time dimension to our outcome variable and treatment:
\begin{itemize}
    \item $Y_{it}$: observed (log) wages of individual $i$ at time $t$
    \item $D_{it}$: union membership of individual $i$ at time $t$
    \item $X_{it}$: observed, time-varying covariates
    \item $A_i$: \textbf{unobserved but fixed} confounders
    \begin{itemize}
         \item Assume $A_i$ is an individual's innate ability, and is fixed over time
         \item $A_i$ should include all other time-invariant characteristics, like biological sex
     \end{itemize}
\end{itemize}
Potential outcomes: $Y_{it}(d)$
\begin{itemize}
    \item $Y_{it} (0)$: Control potential outcome 
    \item $Y_{it} (1)$: Treatment potential outcome
\end{itemize}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Identifying assumptions}

Assume conditional independence holds:
\begin{equation*}
    \EE [Y_{it} (0) \vert A_i, X_{it}, t, D_{it}] = \EE [Y_{it} (0) \vert A_i, X_{it}, t]
\end{equation*}
\vspace{-2ex}
\begin{itemize}
    \item Union membership is as good as randomly assigned conditional on $A_i$, $X_{it}$, and $t$
\end{itemize}
\onslide<2->{%
Assume a linear model for $\EE [Y_{it} (0) \vert \cdot]$, where $\textcolor<2>{Orange}{A_i}$ does not have a time subscript:
\begin{equation*}
    \EE [Y_{it} (0) \vert A_i, X_{it}, t] 
    = \textcolor<4>{MainBlue}{\alpha + \lambda_t + \textcolor<2>{Orange}{A_i^\prime} \gamma + X_{it}^\prime \beta}
\end{equation*}
}%
\onslide<3->{%
Assume the causal effect of union membership is a constant, $\rho$:
\begin{equation*}
    \EE [Y_{it} (1) \vert A_i, X_{it}, t] = \EE[Y_{it} (0) \vert A_i, X_{it}, t]  + \textcolor<4>{Green}{\rho}
\end{equation*}
}%
\onslide<4->{%
The above equations imply:
\begin{equation*}
    \EE [Y_{it} \vert A_i, X_{it}, t, D_{it}] = \textcolor<4>{MainBlue}{\alpha + \lambda_t} + \textcolor<4>{Green}{\rho D_{it}} + \textcolor<4>{MainBlue}{A_i^\prime \gamma + X_{it}^\prime \beta}
\end{equation*}
}%
\onslide<5->{%
Note: these are more restrictive assumptions than we used in previous sections:
\begin{itemize}
    \item We are explicitly assuming a linear, additive functional form
    \item We are assuming the effect of treatment is the same for everyone, in every period ($\rho$ has no $i$ or $t$ subscript)
    \begin{itemize}
        \item {\color{DarkGray}We will relax this next class; it matters a lot for diff-in-diff with staggered timing}
    \end{itemize}
\end{itemize}
}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{The fixed effects model}

Fixed effects model:
\begin{equation*}
    Y_{it} = \alpha_i + \lambda_t + \rho D_{it} + X_{it}^\prime \beta + \epsilon_{it},
\end{equation*}
where:
\begin{equation*}
    \epsilon_{it} \equiv Y_{it} (0) - \EE [Y_{it} (0) \vert A_i, X_{it}, t], \quad \alpha_i = \alpha + A_i^\prime \gamma
\end{equation*}
{\color{DarkGray}$\epsilon_{it}$ is the part of $Y_{it}(0)$ not explained by the model}

\vspace{3ex}
\begin{itemize}
    \item Causal effect of treatment (i.e. union status on wages) is given by $\rho$
    \item Individual fixed effects $\alpha_i$ are parameters to be estimated
    \begin{itemize}
        \item Given by coefficients on dummies for each individual
    \end{itemize}
    \item Time fixed effects $\lambda_t$ are parameters to be estimated
    \begin{itemize}
        \item Given by coefficient on dummies for each time period in the model
    \end{itemize}
\end{itemize}

\vspace{3ex}
Important notes:
\begin{itemize}
    \item $\rho$ is identified only from individuals whose treatment status changes over time (e.g. workers who join or leave a union)
    \item Each element of $X_{it}$ must vary over time for at least some $i$; time-invariant characteristics are absorbed into $\alpha_i$, and their coefficients cannot be estimated
\end{itemize}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Estimating fixed effects in practice}

Fixed effects: estimate a coefficient for a dummy on each individual $i$
\begin{itemize}
    \item This could be a big computational lift
    \begin{itemize}
        \item Example: estimating effect of union membership on wages
        \item Might use Panel Study of Income Dynamics (PSID) data, with data on 5,000 men ($N=5,000$) observed for 20 years ($T=20$)
        \item Estimating coefficients on 4,999 individuals seems computationally difficult
    \end{itemize}
    \item In practice, you don't need to estimate all coefficients
\end{itemize}

\end{frame}


%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{The within transformation}

Consider equation with only individual fixed effects:
\begin{equation*}
    \textcolor<2>{Green}{Y_{it} = \textcolor<1>{Orange}{\alpha_i} + \rho D_{it} + X_{it}^\prime \beta + \epsilon_{it}}
\end{equation*}
Consider the average over all $t$ for individual $i$ e.g. $\bar{Y}_i = \frac{1}{T}\sum_{t=1}^T Y_{it}$
\begin{equation*}
    \textcolor<2>{MainBlue}{\bar{Y}_i = \textcolor<1>{Orange}{\alpha_i} + \rho \bar{D}_i + \bar{X}_i^\prime \beta + \bar{\epsilon}_i}
\end{equation*}
\onslide<2->{%
Subtract the mean equation from the regression, we have the ``de-meaned'' regression:%
}
\begin{align*}
    \onslide<2->{
    \textcolor<2>{Green}{Y_{it}} - \textcolor<2>{MainBlue}{\bar{Y}_i} =& \textcolor<2>{Green}{\textcolor<3>{Orange}{\alpha_i} + \rho D_{it} + X_{it}^\prime \beta + \epsilon_{it}} - \textcolor<2>{MainBlue}{\left( \textcolor<3>{Orange}{\alpha_i} + \rho \bar{D}_i + \bar{X}_i^\prime \beta + \bar{\epsilon}_i \right)}
    } \\
    \onslide<3->{
    =& \textcolor<3>{Orange}{(\alpha_i - \alpha_i)}
    + \rho (D_{it} - \bar{D}_i)
    + (X_{it} - \bar{X}_i)^\prime \beta
    + (\epsilon_{it} - \bar{\epsilon}_i)
    } \\
    \onslide<4->{
    =& \rho (D_{it} - \bar{D}_i)
    + (X_{it} - \bar{X}_i)^\prime \beta
    + (\epsilon_{it} - \bar{\epsilon}_i)
    } \\
    \onslide<5->{
    \alert<5>{\ddot{Y}_{it}} =& \alert<5>{\rho \ddot{D}_{it}
    + \ddot{X}_{it}^\prime \beta
    + \ddot{\epsilon}_{it}}
    }
\end{align*}
\onslide<6->{%
Can estimate $\rho$ from the de-meaned data; much more computationally simple!
\begin{itemize}
    \item Deviations from the mean kill individual fixed effects
    \item Gives the \emph{same} estimate of $\rho$ as regressing on dummies for each individual
    \item Fixed effects estimator often called the ``within'' estimator: it only uses variation \emph{within} each individual over time
    \item With time fixed effects $\lambda_t$ also included, this is called \textbf{two-way fixed effects} (TWFE)
\end{itemize}
}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{First differences}

An alternative to de-meaning is to estimate first differences. Let $\Delta Y_{it} = Y_{it} - Y_{it-1}$:
\begin{align*}
    \Delta Y_{it} =& \textcolor<2>{Green}{Y_{it}} - \textcolor<2>{MainBlue}{Y_{it-1}} \\
    \onslide<2->{
    =& \textcolor<3>{Orange}{(\textcolor<2>{Green}{\alpha_i} - \textcolor<2>{MainBlue}{\alpha_i})}
    + \rho (\textcolor<2>{Green}{D_{it}} - \textcolor<2>{MainBlue}{D_{it-1}})
    + (\textcolor<2>{Green}{X_{it}} - \textcolor<2>{MainBlue}{X_{it-1}})^\prime \beta
    + (\textcolor<2>{Green}{\epsilon_{it}} - \textcolor<2>{MainBlue}{\epsilon_{it-1}})
    } \\
    \onslide<4->{
    =& \alert<4>{\rho \Delta D_{it} + \Delta X_{it}^\prime \beta + \Delta \epsilon_{it}}
    }
\end{align*}
\onslide<5->{%
When there are only 2 periods, the fixed effects and first differenced estimators will be identical.
    \begin{align*}
        Y_{i2} - \bar{Y}_i &= Y_{i2} - \frac{Y_{i2} + Y_{i1}}{2} \\
        &= \frac{2 Y_{i2} - Y_{i2} - Y_{i1}}{2} \\
        &= \alert<5>{\frac{Y_{i2} - Y_{i1}}{2}}
    \end{align*}
\begin{itemize}
    \item  The de-meaned data is proportional to the first-differenced data $\implies$ the fixed effect estimator is the same as the first-differenced estimator
\end{itemize}
}%
\onslide<6->{%
When there are more than 2 periods, the two estimators generally give different estimates:
\begin{itemize}
    \item Fixed effects compares each period to the individual's \emph{average}; first differences compares each period to the \emph{previous} period
    \item Both remove $\alpha_i$, and under our assumptions both estimate the same $\rho$
\end{itemize}
}

\end{frame}


%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Do not use fixed effects for these things}

\textbf{1. Reverse causality} (simultaneity)
\begin{itemize}
    \item Example: regress county crime rates on police per capita (Cornwell and Trumbull, 1994)
    \item Becker (1968): more police $\rightarrow$ less crime; but police spending is itself a function of crime rates
    \item Fixed effects estimate: a \emph{positive} relationship between police and crime
\end{itemize}

\vspace{2ex}
\textbf{2. Time-variant unobserved heterogeneity}
\begin{itemize}
    \item Fixed effects only remove unobserved confounders that are unchanging over time ($\alpha_i$)
    \item If there is a \emph{separate} unobserved confounder that changes over time (not part of $\alpha_i$), it stays in $\epsilon_{it}$ and is correlated with $D_{it}$: ``just another form of omitted variable bias''
    \item Example: effect of marriage on men's wages (Cornwell and Rupert, 1997)
    \begin{itemize}
        \item Possible confounder: ``settling down'' --- a shift in priorities that leads men to both marry and invest more in their careers; it changes over time and is unobserved
    \end{itemize}
\end{itemize}

\end{frame}

\begin{frame}{Cholera example}

In mid-1800s London, cholera was spreading
\begin{itemize}
    \item Awful, often fatal disease
    \item At the time, doctors thought it spread through the air
    \item In fact, it spread through contaminated food and water supply
    \begin{itemize}
        \item Sewage, containing cholera from ill people, would flow into the Thames, which would contaminate the water supply, which would cause more cholera
    \end{itemize}
\end{itemize}

Researcher John Snow suspected that it may be the water supply causing cholera transmission
\begin{itemize}
    \item Several water companies served different areas of the city
    \item In 1852, the \textbf{Lambeth (L)} water company moved their pipes upstream, above the main sewage discharge point
    \item The \textbf{Southwark and Vauxhall (SV)} Waterworks Company served similar households to the Lambeth Company, and did not move their intake point upstream
\end{itemize}
Snow evaluated one of the earliest \textbf{natural experiments}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Cross sectional comparison (fixed effects approach)}

Let:
\begin{itemize}
    \item $Y$: Outcome (cholera deaths)
    \item $D$: Treatment dummy (clean water)
    \item $L$: Lambeth fixed effect
    \item $SV$: Southwark and Vauxhall fixed effect
\end{itemize}
\begin{table}
\begin{tabular}{ll}
\textbf{Company} &\textbf{Outcome} \\
Lambeth & $Y = L + D$ \\
Southwark and Vauxhall & $Y = SV$
\end{tabular}
\end{table}
If estimated causal effect comes from simple comparison of outcomes:
\begin{equation*}
    D + (L - SV)
\end{equation*}
$(L - SV)$ may contain selection bias

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Pre-post comparison (interrupted time series; time fixed effect)}

Let:
\begin{itemize}
    \item $Y$: Outcome (cholera deaths)
    \item $D$: Treatment dummy (clean water)
    \item $L$: Lambeth fixed effect
    \item $T$: Time fixed effect
\end{itemize}
\begin{table}
\begin{tabular}{ll}
\textbf{Company} &\textbf{Outcome} \\
Lambeth before & $Y = L$ \\
Lambeth after & $Y = L + (T + D)$
\end{tabular}
\end{table}
If estimated causal effect comes from simple comparison of outcomes:
\begin{equation*}
    L + (T + D) - L = T + D
\end{equation*}
\begin{itemize}
    \item Eliminates unit-specific fixed effect $L$
    \item $T$ isn't observable, so this can't be estimated
    \begin{itemize}
    \item This is both generally true, and specific to this example: cholera often arrived in waves
\end{itemize}
\end{itemize}




\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Difference-in-differences}

Let:
\begin{itemize}
    \item $D_1$: Pre/Post difference
    \item $D_2$: Cross-sectional difference
\end{itemize}
\begin{table}
\begin{tabular}{lllll}
\hline
\textbf{Company} &\textbf{Time} &\textbf{Outcome} &$D_1$ &$D_2$ \\
\hline\hline
Lambeth                &Before &$Y = L$            &\\
\hline
Lambeth                &After  &$Y = L + (T + D)$  &$T + D$ &$D$\\
\hline
Southwark and Vauxhall &Before &$Y = SV$           & \\
\hline
Southwark and Vauxhall &After  &$Y = SV + T$       &$T$ \\
\end{tabular}
\end{table}
\begin{itemize}
    \item The before-after difference eliminates the company fixed effects
    \item The difference in differences eliminates the time effects
\end{itemize}

\vspace{2ex}
Key assumption: \textbf{Parallel trends}
\begin{itemize}
    \item There is no time-variant company specific unobservables.
    \begin{itemize}
         \item $T$ is the same for all households
         \item Nothing unobserved in Lambeth households that is changing between these two periods that also determines cholera deaths
     \end{itemize} 
\end{itemize}
\end{frame}

\begin{frame}{Card and Krueger (1994)}

Setup: in April 1992, NJ increased the state minimum wage from \$4.25 to \$5.05. PA minimum wage stayed at \$4.25
\begin{itemize}
    \item Two groups: treatment group ($G=1$) and control ($G=0$)
    \item Two periods: before ($T=0$) and after ($T=1$)
    \item Only one group is treated during one period
\end{itemize}

\vspace{2ex}
Data: survey of 400 fast food stores in NJ and PA before and after the minimum wage increase

\vspace{2ex}
Results: Card and Krueger (1994) find no evidence that increasing the minimum wage reduced employment

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Card and Krueger (1994): four averages and three subtractions}

\begin{equation*}
    \hat\delta^{2\times 2} = \big(\bar y_{NJ}^{post} - \bar y_{NJ}^{pre}\big) - \big(\bar y_{PA}^{post} - \bar y_{PA}^{pre}\big)
\end{equation*}

Average full-time-equivalent employment per store:
\begin{table}
\begin{tabular}{lccc}
\hline
 & \textbf{Before} & \textbf{After} & \textbf{After $-$ Before} \\
\hline\hline
NJ (treated)  & 20.44 & 21.03 & 0.59 \\
PA (control)  & 23.33 & 21.17 & $-2.16$ \\
\hline
% NJ $-$ PA     & $-2.89$ & $-0.14$ & \\
% \hline
\end{tabular}
\end{table}

\begin{itemize}
    % \item Cross-sectional comparison (after): $-0.14$
    \item Pre-post comparison (NJ): $0.59$
    \item Pre-post comparison (PA): $-2.16$
    \item Diff-in-diff: $0.59 - (-2.16) = \mathbf{2.76}$
\end{itemize}

\vspace{2ex}
\emph{Source: Card and Krueger (1994), Table 3}
\end{frame}

\begin{frame}{Diff-in-diff using potential outcomes}

Set-up:
\begin{itemize}
    \item Two groups (treatment and control): $G=0$ and $G=1$
    \item Two periods (before and after the treatment): $T=0$ and $T=1$
    \item Only one group is treated during one period
\end{itemize}

\vspace{2ex}
Using the potential outcomes framework:
\begin{itemize}
    \item $D$: treatment indicator, defined by $D = T \cdot G$
    \item $Y (d)$: potential outcome
    \item $Y$: observed outcome variable
    \begin{equation*}
        Y = D \cdot Y (1) + (1 - D) \cdot Y (0)
    \end{equation*}
\end{itemize}

\vspace{2ex}
\textbf{Key assumption: Common trends} $\EE [ Y(0) \vert G, T =1 ] - \EE [Y(0) \vert G, T= 0]$ does not depend on $G$



\end{frame}

Recall $Y = D \cdot Y (1) + (1 - D) \cdot Y (0)$ and {\color<3>{orange}$D = T \cdot G$}. The observed difference in differences is given by:
\begin{align*}
    &(\EE [{\color<2>{cyan} Y} \vert G = 1, T = 1] - \EE [{\color<2>{cyan}Y} \vert G = 1, T = 0])
    - (\EE [{\color<2>{cyan}Y} \vert G = 0, T = 1] - \EE [{\color<2>{cyan}Y} \vert G = 0, T = 0]) \\
    \only<2-4>{
    \onslide<2->{=& (
            \EE [{\color<2>{cyan} D Y(1) + (1 - D) Y(0)} \vert G = 1, T = 1] 
            - \EE [{\color<2>{cyan} D Y(1) + (1 - D) Y(0)} \vert G = 1, T = 0]
        ) \\
        & - (
            \EE [{\color<2>{cyan} D Y(1) + (1 - D) Y(0)} \vert G = 0, T = 1] 
            - \EE [{\color<2>{cyan} D Y(1) + (1 - D) Y(0)} \vert G = 0, T = 0]
        ) \\}
    \onslide<3->{=& (
            \EE [{{\color<3>{orange}TG} Y(1) + (1 - {\color<3>{orange}TG}) Y(0)} \vert G = 1, T = 1] 
            - \EE [{{\color<3>{orange}TG} Y(1) + (1 - {\color<3>{orange}TG}) Y(0)} \vert G = 1, T = 0]
        ) \\
        & - (
            \EE [{{\color<3>{orange}TG} Y(1) + (1 - {\color<3>{orange}TG}) Y(0)} \vert G = 0, T = 1] 
            - \EE [{{\color<3>{orange}TG} Y(1) + (1 - {\color<3>{orange}TG}) Y(0)} \vert G = 0, T = 0]
        ) \\}
    % \onslide<4->{=& (
    %         \EE [{1 Y(1) + (1 - {\color<4>{orange}1}) Y(0)} \vert G = 1, T = 1] 
    %         - \EE [{0 Y(1) + (1 - {\color<4>{orange}0}) Y(0)} \vert G = 1, T = 0]
    %     ) \\
    %     & - (
    %         \EE [{0 Y(1) + (1 - {\color<4>{orange}0}) Y(0)} \vert G = 0, T = 1] 
    %         - \EE [{0 Y(1) + (1 - {\color<4>{orange}0}) Y(0)} \vert G = 0, T = 0]
    %     ) \\}
    }  % end only
    \onslide<4->{=& (
            \EE [{Y(1)} \vert G = 1, T = 1] 
            - \EE [{Y(0)} \vert G = 1, T = 0]
        ) \\
        & - (
            \EE [{Y(0)} \vert G = 0, T = 1] 
            - \EE [{Y(0)} \vert G = 0, T = 0]
        ) \\}
    \onslide<5->{
    =& ({\color<6>{cyan} \EE [{Y(1)} \vert G = 1, T = 1]}
            {\color<6>{Green} - \EE [{Y(0)} \vert G = 1, T = 0]}
        ) \\
        & {\color<6>{Orange}- (
                    \EE [{Y(0)} \vert G = 0, T = 1] 
                    - \EE [{Y(0)} \vert G = 0, T = 0]
                )} \\
        & {\color<5>{red}
        {\color<6>{HunterPurple} + \EE [{Y(0)} \vert G = 1, T = 1]} 
        {\color<6>{MainBlue}- \EE [{Y(0)} \vert G = 1, T = 1]}}
    } \\
    \onslide<6->{
    =& 
        \underbrace{
            {\color<6>{cyan}\EE [{Y(1)} \vert G = 1, T = 1] }
            {\color<6>{MainBlue}- \EE [{Y(0)} \vert G = 1, T = 1]}
        }_{\text{ATT}} \\
        & \underbrace{{
                    {\color<6>{HunterPurple} + \EE [{Y(0)} \vert G = 1, T = 1]}
                    {\color<6>{Green} - \EE [{Y(0)} \vert G = 1, T = 0]}
                }}_{\text{Counterfactual difference for treated group}} \\
        & \underbrace{{\color<6>{Orange}- (
                            \EE [{Y(0)} \vert G = 0, T = 1] 
                            - \EE [{Y(0)} \vert G = 0, T = 0]
                        )}}_{\text{Difference for control}}
    }
\end{align*}
\end{frame}

\begin{frame}{Parallel trends}

Observed differences in differences equals: 

\begin{multline*}
\underbrace{
            {\EE [{Y(1)} \vert G = 1, T = 1] }
            {- \EE [{Y(0)} \vert G = 1, T = 1]}
        }_{\text{ATT}} \\
        \underbrace{{
                    {+ \EE [{Y(0)} \vert G = 1, T = 1]}
                    { - \EE [{Y(0)} \vert G = 1, T = 0]}
                }}_{\text{Counterfactual difference for treated group}} \\
        \underbrace{{- (
                            \EE [{Y(0)} \vert G = 0, T = 1] 
                            - \EE [{Y(0)} \vert G = 0, T = 0]
                        )}}_{\text{Difference for control}}
\end{multline*}
The last two terms are the \textbf{non-parallel trends bias}. DiD $=$ ATT only if it is zero:
\begin{multline*}
    \EE [{Y(0)} \vert G = 1, T = 1] - \EE [{Y(0)} \vert G = 1, T = 0] \\
    = \EE [{Y(0)} \vert G = 0, T = 1] - \EE [{Y(0)} \vert G = 0, T = 0]
\end{multline*}
\emph{In words:} Absent treatment, the treated group would have followe`d the same trend as the control group

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Parallel trends (cont.)}

Suppose parallel trends holds:
\begin{align*}
    \alert{\EE [{Y(0)} \vert G = 1, T = 1] - \EE [{Y(0)} \vert G = 1, T = 0]} \\
    = \EE [{Y(0)} \vert G = 0, T = 1] - \EE [{Y(0)} \vert G = 0, T = 0]
\end{align*}
Consider the impact of a training program on earnings:
\begin{itemize}
    \item \alert{First term:} evolution of earnings for trainees had they not trained 
    \begin{itemize}
        \item This is fundamentally untestable
    \end{itemize}

    \item Evolution of mean earnings for non-trainees


\end{itemize}


\end{frame}

\begin{frame}{From the 2$\times$2 to regression}

\begin{equation*}
    Y = \alpha + \gamma G + \lambda T + \delta (T \times G) + \epsilon
\end{equation*}

Each of the four averages maps to coefficients:
\begin{table}
\begin{tabular}{lccc}
\hline
 & \textbf{Before} & \textbf{After} & \textbf{After $-$ Before} \\
\hline\hline
NJ ($G=1$) & $\alpha + \gamma$ & $\alpha + \gamma + \lambda + \delta$ & $\lambda + \delta$ \\
PA ($G=0$) & $\alpha$          & $\alpha + \lambda$                   & $\lambda$ \\
\hline
\end{tabular}
\end{table}
Diff-in-diff: $(\lambda + \delta) - \lambda = \delta$

\begin{itemize}
    \item OLS $\hat\delta$ is \emph{numerically identical} to the 2$\times$2: $\hat\delta = 2.76$
\end{itemize}

\vspace{2ex}
\textbf{Why use regression?}
\begin{itemize}
    \item Same estimate, but delivers standard errors and hypothesis tests
    \item Easy to extend: covariates, more groups, more periods
\end{itemize}

\vspace{2ex}
\textbf{Why use 2x2?}
\begin{itemize}
    \item Easy to explain to non-practitioners
\end{itemize}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Three equivalent regressions}

In the 2$\times$2, all three give the same $\hat\delta$:
\begin{enumerate}
    \item Interaction:
    \begin{equation*}
        Y_{it} = \alpha + \gamma G_i + \lambda T_t + \delta (T_t \times G_i) + \epsilon_{it}
    \end{equation*}
    \item Two-way fixed effects (TWFE), with $D_{it} = T_t \times G_i$:
    \begin{equation*}
        Y_{it} = \alpha_i + \lambda_t + \delta D_{it} + \epsilon_{it}
    \end{equation*}
    \item Long difference:
    \begin{equation*}
        \Delta Y_i = \lambda + \delta G_i + \Delta \epsilon_i
    \end{equation*}
\end{enumerate}

\begin{itemize}
    \item TWFE and first differences are the fixed effects tools from earlier in this lecture
    \item With more groups and periods, TWFE is the workhorse, but with \alert{staggered timing} it no longer equals a clean 2$\times$2 (next lecture)
\end{itemize}

\end{frame}

\begin{frame}{Inference in diff-in-diff}

\begin{itemize}
    \item Many studies employing DD strategies use data from many years—not just one pre-treatment and one post-treatment period like Card and Krueger (1994)

    \item The variables of interest in many of these setups only vary at a group level, such as the state, and outcome variables are often serially correlated

    \begin{itemize}
        \item In Card and Krueger (1994), it is very likely for instance that employment in each state is not only correlated within the state but also serially correlated
    \end{itemize}

    \item Bertrand, Duflo, and Mullainathan (2004) point out that the conventional standard errors often severely understate the standard deviation of the estimators, and so standard errors are biased downward, “too small,” and therefore overreject the null hypothesis
\end{itemize}

Bertrand, Duflo, and Mullainathan (2004) propose the following solutions:
\begin{enumerate}
    \item Block bootstrapping standard errors

    \item Aggregating the data into one pre and one post period

    \item \alert{Clustering standard errors at the group level} \emph{(You can just do this one)}

\end{enumerate}


\end{frame}


%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}{Checking for parallel trends}

Parallel trends is fundamentally untestable
\begin{itemize}
    \item Even if trends were the same before the treatment, there is no guarantee they'd be the same after
    \item That said, you can do intuitive checks to see if this assumption is reasonable
\end{itemize}

\vspace{3ex}
\begin{enumerate}
    \item Plot the raw data, and inspect whether the pre-treatment dynamics of the treatment group differed from that of the control group

    \item Estimate an \textbf{event study}: a regression with treatment leads and lags
    \begin{itemize}
        \item Leads measure differential pre-trends; lags trace out effects over time
    \end{itemize}
\end{enumerate}

\vspace{3ex}
Parallel pre-trends are \emph{suggestive}, not a test: they support, but cannot prove, parallel trends after treatment
\end{frame}

\begin{frame}{Diff-in-diff in the courtroom}

A diff-in-diff estimate is a \emph{claim}, not evidence
\begin{itemize}
    \item Parallel trends is untestable, so a table of coefficients alone won't persuade a skeptic
    \item Build a case that rules out alternative explanations
\end{itemize}

\vspace{2ex}
Elements of a convincing diff-in-diff study:
\begin{enumerate}
    \item \textbf{Bite:} the policy changed what it was supposed to change
    \item \textbf{Event studies:} no differential pre-trends
    \item \textbf{Falsification:} no effect where there shouldn't be one
    \item \textbf{Main results}
    \item \textbf{Mechanisms:} why the effect makes sense
\end{enumerate}

\vspace{2ex}
\emph{Source: Cunningham, Mixtape Section 9.7}
\end{frame}
